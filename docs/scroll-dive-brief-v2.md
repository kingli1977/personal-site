# 水下下潜滚动 Demo 任务书 v2.0（媒介修正版）

## 〇、为什么有 v2.0：前两轮失败根因

v1/v1.1 按「GSAP + CSS 分层视差」路线返修两轮，量化指标（视差位移量、粒子数、动画组数）全绿，但人眼观感「完全没有改善」。

根因不是执行不到位，是**媒介判错**：该效果的原创站（gyut.cn「Ocean — Closer to the ocean」，经源码核实）是**单文件 WebGL 片元着色器 + 射线步进（raymarching）海面**，整站 JS 仅 11KB，不用 three.js / GSAP / 视频素材，DOM 里也没有任何分层视差。CSS 合成路线在原理上无法复刻"整屏像素每帧被 3D 波面方程重算"的效果，继续微调 CSS 无意义，整版重写。

v1/v1.1 的配方卡与实现仅作存档参考，勿再沿用。

## 一、参照物

- 效果参照站：https://gyut.cn/ （点「Watch the film」= 12 秒自动滚动走完全程；抖音原视频即录屏）
- **只研究其技术原理与视觉构成，禁止照抄其源码**（著作权）。海浪部分采用公开经典的 TDM / Seascape 技术路线自行实现，这是 three.js 官方海洋示例的同源公开算法。

## 二、技术要求

### 2.1 媒介

- 单个全屏 `<canvas>` + **raw WebGL1 + GLSL ES 1.0 片元着色器**（有意不用 three.js，保持与原作同级的轻量）
- 顶点着色器仅为全屏四边形透传
- 降级方案：WebGL 不可用时显示一张静帧 + 提示，不许白屏

### 2.2 着色器必须实现的成分（逐项都是肉眼可见的效果，不许偷工减料）

| # | 成分 | 规格 |
|---|---|---|
| 1 | 天空 | 日落色渐变 + fbm 分形噪声云（随时间缓慢漂移）+ 太阳圆盘与光晕 |
| 2 | 海面高度场 | ≥4 层倍频程正弦波（TDM 波浪，带 \|sin\| 型 chop 波峰），随时间推进 |
| 3 | 求交 | 视线与海面的 raymarching 求交（分段搜索 + 二分精化），法线用有限差分 |
| 4 | 光照 | 菲涅尔混合「天空反射色」与「深水折射色」；太阳镜面高光用高次幂（波光的来源）；远处大气雾化 |
| 5 | 水线 | 画面中部一条被两条正弦波扰动的水线，随下潜进度上移；水面附近一条透镜式高光细线 |
| 6 | 水下 | 程序化水体渐变；≥5 条缓慢摆动的体积光柱（指数衰减截面）；海面高度场投影到头顶形成的焦散微光；≥15 颗缓慢上浮的微尘光点 |
| 7 | 后期 | 轻微暗角 + gamma 校正 |
| 8 | 天空照片 | 允许用 1 张真实日落照片衔接地平线（Unsplash 搜 "sunset ocean horizon"，放本地目录、可替换），与程序化天空按高度混合 |

### 2.3 滚动驱动

- 滚动进度 → 着色器 `depth` uniform（这是本效果的核心驱动方式，**不是 DOM 动画**）
- 下潜程度用 smoothstep 过渡；相机高度随进度从约 1.1 降到约 0.14，实现"穿过波面看水下"
- 指针视差：鼠标位置轻微偏移相机
- DOM 保持极简：intro 标题淡出 + 若干文案段落淡入；**不做分层视差**

### 2.4 工程要求

- 沿用 `demo/scroll-dive/` 目录，删除 v1 的 CSS 分层实现后重写（index.html / styles.css / main.js）
- 页面标题：`Ocean — Closer to the ocean.`
- 渲染循环 requestAnimationFrame；桌面 Chrome ≥50fps（M 系列 Mac）
- `prefers-reduced-motion` 时暂停动画渲染
- 提供「Watch the film」式按钮：12 秒自动滚动走完全程（方便录屏验收）
- 375px 移动宽度无横向滚动

## 三、验收标准（交付前必须逐项自检并附证据）

1. **海面活性**：录屏 12 秒一遍，海面段必须可见波光闪烁与云层漂移，不是静止渐变
2. **穿越瞬间**：水线漫过画面时必须可见波峰起伏，不是一条直线平切
3. **水下活性**：光柱与上浮光点肉眼可见
4. **性能**：Performance 面板录 5 秒无 long task
5. **新分支**：从 `main` 切出 `demo/scroll-dive-v2` 提交，给出 Cloudflare Pages 预览链接
