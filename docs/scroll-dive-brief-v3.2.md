# 返修单 v3.2：水下内容复活（暗底保住 + 点睛恢复）

背景：v3.1 后用户反馈"海平面以下黑色一片什么都没有"。实测确认：45%/70%/90% 水下亮像素占比仅 0.03-0.04%，光柱/焦散/粒子在 v2.1 校准中被过度压暗（光柱×0.28、焦散0.10、粒子减半且缩小）。参照原作：水下是"暗底+可见点睛"——基色近黑，但光柱核心局部亮度 gamma L≈60-90、上浮粒子是清晰可见的亮点。本轮把点睛恢复到可辨识，同时守住暗底。

## 修改（只动 frag.glsl 的 underwater() 及相关权重）

1. 光柱：恢复为可辨识的竖向光束
   - 幅度从当前×0.28 提到×0.6（顶部核心达到 gamma L 55-85）
   - 高度衰减用 y² 型：只在屏顶 40% 高度内明显，向下自然消散
   - 数量 6 条，保留缓慢摆动
2. 焦散（水面投影微光）：0.10 → 0.22，限定水线下方 8-25% 高度带
3. 粒子：数量 ≥16，恢复可见亮度（gamma L 90-140 的孤立亮点），半径恢复到屏高 0.15-0.3%，保留缓慢上浮
4. 深度带基色、深度衰减 exp(-down*3.15)、水线、40%后渐进压暗系数全部不动

## 验收（双向指标，防"水族馆"复发也防"黑屏"复发）

暗底（不回退）：
- 45% 全屏 L p50 ≤ 35；90% p50 ≤ 20
- 暗占比：45% 时 L<50 像素 ≥ 85%；90% 时 ≥ 92%

点睛（本轮新增，必须过）：
- 45% 进度屏顶 30% 区域：L∈[55,140] 像素占比 ≥ 1.5%（光柱可读）
- 45% 与 70% 各检出 ≥12 个孤立亮点（局部极大值 L≥90，互不粘连=粒子可辨）
- 45% 全屏 p99 ≤ 120（给点睛留空间但封顶防过亮）
- 90% 深水：点睛变暗但仍可辨（顶 30% 区域 L∈[40,100] 占比 ≥ 0.8%）
